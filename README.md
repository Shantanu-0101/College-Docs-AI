## ...College Document AI...
- Developed a Retrieval-Augmented Generation (RAG) based AI chatbot using Streamlit that enables users to upload
  college PDFs/notes and get accurate, context-aware answers.
  
- Processed and embedded multiple PDF documents into a FAISS vector store using Sentence-BERT embeddings for fast
  semantic retrieval.
  
- Integrated Groq LLM (Llama 3.3) with custom prompt engineering to deliver accurate, context-grounded responses.
  Built responsive frontend using Streamlit, enabling seamless document upload and conversational interaction
